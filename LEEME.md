# APPINITY · Claude desde cero

Este paquete contiene requisitos e instrucciones, no código de aplicación. Extrae todo en un repositorio nuevo llamado appinity-claude. No lo copies sobre la implementación de Codex.

Empieza por docs/APPINITY_Guia_Claude_Desde_Cero.md. Abre la carpeta en Claude Code y envía prompts/00_empezar_desde_cero.md. La primera entrega debe construir fases 0 y 1; después debes probar la demo antes de avanzar.

CLAUDE.md queda en la raíz y las carpetas docs/, prompts/ y comparacion/ a su lado. Mantén estos archivos en Git. No se incluyen credenciales ni datos personales.
