# Probar antes de avanzar

Lee CLAUDE.md, docs/APPINITY_Especificacion.md, docs/decisions.md y docs/progress.md. Trabaja exclusivamente en appinity-claude.

Antes de continuar, ayúdame a comprobar las fases 0 y 1. Ejecuta en tu entorno las instrucciones del README y corrige los fallos. Dame después un paso a paso para mi ordenador y mi teléfono, con cada comando y resultado esperado.

Quiero verificar instalación, BD/Redis, migraciones y seed repetidos sin duplicados, API protegida y health, cuatro pestañas, imágenes con fallback, datos claramente simulados y separación entre conocido, consumido y preferencia. Comprueba que el teléfono alcance la API: localhost del teléfono no es mi ordenador. Explica Expo Go o development build según dependencias reales. Registrar como pendiente lo que deba probar yo. No avanzar a fase 2 hasta que confirme la prueba.
