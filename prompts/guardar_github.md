# Guardar cambios

Te autorizo a subir a mi repositorio appinity-claude los archivos nuevos y los cambios que vayas realizando, y a mantener actualizada la documentación con el progreso. Usa una rama por fase y crea una pull request si está disponible. No subas secretos ni datos personales. Al terminar, dime el commit y el enlace de la rama o PR. No modifiques el repositorio de Codex.
