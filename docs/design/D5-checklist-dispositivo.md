# D5 · Comprobación en el teléfono (accesibilidad)

Lo automático ya está hecho: contraste AA de todos los pares de tokens, roles y etiquetas de los pulsables y campos
con etiqueta visible. Esto solo se puede comprobar en el propio teléfono. Unos 15 minutos.

## 1. Texto grande

Ajustes de Android → Pantalla → Tamaño de fuente al máximo (y «Tamaño de visualización» también, si existe).

- [ ] Inicio: el título de la tarjeta, la categoría y el motivo se leen enteros y los botones del mazo no se tapan.
- [ ] Barra inferior: las etiquetas crecen un poco (máximo 1,3×) y no se cortan.
- [ ] Personas: el porcentaje de afinidad y el nombre no se pisan.
- [ ] Perfil: «Tus gustos» y las acciones de cada fuente se reorganizan en varias líneas sin salirse.
- [ ] Chat: las burbujas y la caja de escribir crecen; el botón de enviar sigue visible.

## 2. TalkBack

Ajustes → Accesibilidad → TalkBack. Desliza a la derecha para avanzar y toca dos veces para activar.

- [ ] Barra inferior: lee «Inicio», «Categorías», «Personas» (con los mensajes pendientes) y «Perfil».
- [ ] Tarjeta de Inicio: lee el título, la categoría y el motivo; los botones dicen qué hacen («Descartar», «Conservar»,
      «Deshacer»).
- [ ] Persona: lee el nombre y la afinidad; el botón de chat o de amistad dice su acción.
- [ ] Chat: la cabecera dice que abre el perfil; un mensaje fallido dice «Reintentar».
- [ ] Alta y acceso local: cada campo lee su etiqueta («Ciudad (opcional)», «Código»), no solo el ejemplo.
- [ ] Ninguna imagen decorativa se lee como «imagen» sin más.

## Cómo informar

Basta con el número del punto y lo que pasa (p. ej., «1.3: el 86 % tapa el nombre»). Una captura ayuda si es visual.
